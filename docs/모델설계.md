## 1. 프로젝트 개요

### 프로젝트명
**AI 기반 드론 부품 자동 검사 시스템**

### 목표
드론 이미지를 입력받아 각 부품(암, 본체, 카메라, 랜딩 기어, 프로펠러)을 픽셀 단위로 자동 세그멘테이션하고, 부품 누락 및 이상을 탐지하는 딥러닝 모델 개발

### 기대 효과
- 드론 검사 시간 단축 (수작업 → 자동화)
- 부품 결함 및 누락 조기 발견
- 일관된 품질 검사 기준 제공

## 2. 문제 정의

### 태스크
**Semantic Segmentation** (의미론적 분할)

이미지의 모든 픽셀을 아래 6개 클래스 중 하나로 분류:

| 클래스 ID | 클래스명 | 설명 | 색상 코드 |
|-----------|----------|------|-----------|
| 0 | background | 배경 | - |
| 1 | arm | 드론 암 | 주황색 (#FF8000) |
| 2 | body | 본체 | 빨간색 (#FF0000) |
| 3 | camera | 카메라 | 초록색 (#00FF00) |
| 4 | landing_gear | 랜딩 기어 | 파란색 (#0000FF) |
| 5 | propeller | 프로펠러 | 노란색 (#FFFF00) |

### 주요 도전 과제
1. **클래스 불균형**: 배경 픽셀이 전체의 ~90% 차지
2. **작은 객체**: 카메라, 랜딩 기어 등 일부 부품은 픽셀 수가 적음
3. **복잡한 경계**: 부품 간 경계가 모호하거나 겹침
4. **조명 변화**: 다양한 촬영 환경으로 인한 색상/밝기 차이

## 4. 모델 아키텍처

### U-Net 선택 이유
1. **세그멘테이션에 특화**: 픽셀 단위 예측에 최적화된 인코더-디코더 구조
2. **Skip Connection**: 고해상도 특징을 보존하여 정밀한 경계 예측
3. **적은 데이터로도 학습 가능**: 전이 학습(Transfer Learning) 활용 시 효율적
4. **빠른 추론 속도**: 실시간 검사 시스템에 적합

### 모델 구조

```
│  │ 512×512×64  │                   │                       │
```

### 상세 스펙
- **Encoder**: VGG16-BN (Batch Normalization 포함)
- **사전 학습 가중치**: ImageNet
- **입력 크기**: 512 × 512 × 3 (RGB)
- **출력 크기**: 512 × 512 × 6 (클래스별 확률 맵)
- **총 파라미터**: 23.7M (전부 학습 가능)
- **라이브러리**: `segmentation_models_pytorch` (SMP)

### 코드 예시
```python
import segmentation_models_pytorch as smp

model = smp.Unet(
    encoder_name="vgg16_bn",        # VGG16 with BatchNorm
    encoder_weights="imagenet",     # ImageNet pretrained
    in_channels=3,                  # RGB 입력
    classes=6                       # 6개 클래스
)
```

## 5. 데이터 전처리 및 증강

### 전처리 (Preprocessing)
모든 이미지와 마스크에 공통 적용:

1. **리사이즈**: 512 × 512 (모델 입력 크기 통일)
2. **정규화**: ImageNet 평균/표준편차 사용
   ```python
   mean = [0.485, 0.456, 0.406]
   std = [0.229, 0.224, 0.225]
   ```

### 데이터 증강 (Augmentation)
학습 시에만 적용하여 모델의 일반화 성능 향상:

| 기법 | 파라미터 | 적용 확률 |
|------|----------|-----------|
| **HorizontalFlip** | - | 50% |
| **VerticalFlip** | - | 30-50% |
| **ShiftScaleRotate** | shift=0.1, scale=0.1-0.2, rotate=20-45° | 50% |
| **RandomBrightnessContrast** | brightness=0.2, contrast=0.2 | 50% |

### 증강 효과
- **회전/이동**: 다양한 각도의 드론 이미지 학습
- **밝기/대비 조정**: 조명 변화에 강건한 모델 생성
- **플립**: 좌우/상하 대칭 데이터 생성

### 코드 예시
```python

from albumentations.pytorch import ToTensorV2

# 학습용 변환

    A.Resize(512, 512),
```

## 6. 손실 함수

### Combined Loss 사용
**CrossEntropyLoss + DiceLoss**를 결합하여 각각의 장점 활용

### 6.1 Cross Entropy Loss
- **특징**: 픽셀별 분류 오차를 직접 계산
- **장점**: 클래스별 가중치 부여 가능 (클래스 불균형 해결)
- **단점**: 작은 객체에 대한 민감도 낮음

### 6.2 Dice Loss
- **특징**: IoU(Intersection over Union) 기반 손실
- **장점**: 작은 객체도 잘 학습 (픽셀 수에 덜 민감)
- **단점**: 클래스 불균형 처리 어려움

### 6.3 Combined Loss 수식
```
Loss = α × CrossEntropyLoss + β × DiceLoss
```
- **α, β**: 가중치 (보통 α=β=0.5)

### 클래스 가중치 (Class Weights)
배경 클래스의 지배를 완화하고 작은 부품(카메라, 랜딩 기어) 학습 강화:
```python
# 예시 (역빈도 기반)
class_weights = torch.tensor([
    0.1,   # background (많음 → 가중치 낮음)
    2.0,   # arm
    1.5,   # body
    3.0,   # camera (적음 → 가중치 높음)
    5.0,   # landing_gear (가장 적음)
    2.5    # propeller
])
```

### 코드 예시
```python
import torch.nn as nn

class CombinedLoss(nn.Module):
    def __init__(self, class_weights=None, alpha=0.5, beta=0.5):
        super().__init__()
        self.ce = nn.CrossEntropyLoss(weight=class_weights)
        self.dice_weight = beta
        self.ce_weight = alpha

    def dice_loss(self, pred, target, num_classes=6):
        pred = torch.softmax(pred, dim=1)
        dice = 0
        for c in range(num_classes):
            pred_c = pred[:, c]
            target_c = (target == c).float()
            intersection = (pred_c * target_c).sum()
            union = pred_c.sum() + target_c.sum()
            dice += (2 * intersection + 1e-7) / (union + 1e-7)
        return 1 - dice / num_classes

    def forward(self, pred, target):
        ce_loss = self.ce(pred, target)
        dice_loss = self.dice_loss(pred, target)
        return self.ce_weight * ce_loss + self.dice_weight * dice_loss
```

## 7. 학습 설정

### Optimizer
**AdamW** (Adam with Weight Decay)
- **Learning Rate**: 5 × 10⁻⁴ (0.0005)
- **Weight Decay**: 1 × 10⁻⁴ (정규화, 과적합 방지)
- **Betas**: (0.9, 0.999)

### Learning Rate Scheduler
**CosineAnnealingWarmRestarts**
- **주기적 재시작**: 학습률을 주기적으로 리셋하여 로컬 최적점 탈출
- **T_0**: 첫 주기 길이 (에포크 수)
- **T_mult**: 2 (주기마다 2배씩 증가)
- **eta_min**: 최소 학습률

이 스케줄러는 학습 중반 이후 plateau(정체)를 방지하고 더 나은 수렴점을 찾는 데 효과적입니다.

```python
from torch.optim import AdamW
from torch.optim.lr_scheduler import CosineAnnealingWarmRestarts

optimizer = AdamW(
    model.parameters(),
    lr=5e-4,
    weight_decay=1e-4
)

scheduler = CosineAnnealingWarmRestarts(
    optimizer,
    T_0=10,        # 첫 재시작까지 10 에포크
    T_mult=2,      # 주기 2배씩 증가
    eta_min=1e-6   # 최소 학습률
)
```

## 8. 학습 과정

### 학습 환경
- **프레임워크**: PyTorch 2.0+
- **디바이스**: GPU (CUDA) / MPS (Apple Silicon) / CPU 자동 선택
- **학습 시간**: 약 X시간 (44 에포크 기준, GPU 사양에 따라 변동)

### 학습 절차
```
for epoch in 1 to 44:
    ┌─────────────────────────────┐
    │  1. Training Phase          │
    │     - Forward pass          │
    │     - Loss 계산              │
    │     - Backward pass          │
    │     - Optimizer step         │
    └─────────────────────────────┘
              ↓
    ┌─────────────────────────────┐
    │  2. Validation Phase        │
    │     - 증강 없이 평가          │
    │     - mIoU, Dice 계산        │
    └─────────────────────────────┘
              ↓
    ┌─────────────────────────────┐
    │  3. Scheduler Step          │
    │     - Learning Rate 조정     │
    └─────────────────────────────┘
              ↓
    ┌─────────────────────────────┐
    │  4. 체크포인트 저장          │
    │     - Best mIoU 기준         │
    │     - 모델 상태 저장          │
    └─────────────────────────────┘
```

### 체크포인트 저장
Best Validation mIoU를 기록한 모델을 저장:
```python
if val_iou > best_iou:
    best_iou = val_iou
    torch.save({
        'epoch': epoch,
        'model_state_dict': model.state_dict(),
        'optimizer_state_dict': optimizer.state_dict(),
        'val_iou': val_iou,
        'val_dice': val_dice
    }, 'best_model_v2.pth')
```

### 학습 모니터링
각 에포크마다 기록:
- Train Loss, Train IoU
- Validation Loss, Validation IoU
- mIoU (Mean IoU), mDice (Mean Dice)
- Pixel Accuracy, FWIoU (Frequency Weighted IoU)
- Learning Rate

이 데이터는 `history2.json`에 저장되어 프론트엔드에서 시각화됩니다.

## 10. 모델 추론

### 추론 프로세스
```
입력 이미지 (RGB)
       ↓
1. 전처리 (Resize + Normalize)
       ↓
2. 모델 Forward Pass
   → Logits: (1, 6, 512, 512)
       ↓
3. Softmax (확률 변환)
   → Probabilities: (1, 6, 512, 512)
       ↓
4. ArgMax (클래스 예측)
   → Mask: (1, 512, 512)
       ↓
5. 원본 크기로 복원
   → Final Mask: (H, W)
       ↓
6. 후처리
   ├─ 컬러 마스크 생성
   ├─ 오버레이 이미지 생성
   ├─ 클래스별 픽셀 분포 계산
   ├─ 부품 검출 여부 판단
```

### 추론 코드 예시
```python
def predict(image: np.ndarray, alpha=0.5):
    # 1. 전처리
    image_tensor = preprocess_image(image).to(DEVICE)

    # 2. 추론
    with torch.no_grad():
        output = MODEL(image_tensor)  # (1, 6, 512, 512)
        probs = torch.softmax(output, dim=1).squeeze(0)  # (6, 512, 512)
        mask = torch.argmax(output, dim=1).squeeze(0)    # (512, 512)

    # 3. 후처리
    mask = mask.cpu().numpy()
    probs = probs.cpu().numpy()

    # 4. 원본 크기로 복원
    mask_resized = resize_to_original(mask, image.shape[:2])

    # 5. 컬러 마스크 및 오버레이 생성
    colored_mask = apply_colors(mask_resized)
    overlay = create_overlay(image, colored_mask, alpha)

    # 6. 통계 및 이상 탐지
    stats = calculate_statistics(mask_resized, probs)
    anomalies = detect_anomalies(stats)

    return {
        "mask": mask_resized,
        "colored_mask": colored_mask,
        "overlay": overlay,
        "class_distribution": stats["distribution"],
        "part_detection": stats["detection"],
        "confidence_scores": stats["confidence"],
        "anomaly_detection": anomalies,
        "overall_confidence": stats["overall"]
    }
```

#### 2. 낮은 신뢰도 감지

```python
for part, confidence in confidence_scores.items():
```

```python
detection_rate = len(detected_parts) / len(expected_parts) * 100
```
