## 방법 2: Docker 배포

### 1️⃣ Docker Compose 사용

#### A. `docker-compose.yml` 파일

프로젝트 루트에 파일 생성:

```yaml
version: '3.8'

services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    volumes:
      - ./models:/app/models
      - ./backend:/app
    environment:
      - PYTHONUNBUFFERED=1
    restart: unless-stopped

  frontend:
    image: node:18-alpine
    working_dir: /app
    volumes:
      - ./frontend:/app
      - /app/node_modules
    ports:
      - "5173:5173"
    command: sh -c "npm install && npm run dev -- --host"
    environment:
      - VITE_API_URL=http://localhost:8000
    depends_on:
      - backend
    restart: unless-stopped
```

#### B. 실행

```bash
# Docker Compose로 전체 시스템 실행
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 중지
docker-compose down
```

## 모델 파일 처리

### 방법 1: 외부 스토리지 사용 (추천)

#### A. Google Drive에 업로드

```bash
# 1. models/final_model.pth를 Google Drive에 업로드
# 2. 공유 링크 생성 (누구나 볼 수 있음)
# 3. 파일 ID 추출:
#    https://drive.google.com/file/d/{FILE_ID}/view
```

#### B. 서버 시작 시 다운로드

`backend/download_model.py` 생성:

```python
import os
import requests
from pathlib import Path

def download_model():
    model_path = Path(__file__).parent.parent / "models" / "final_model.pth"

    if model_path.exists():
        print(f"Model already exists at {model_path}")
        return

    # Google Drive 파일 ID
    file_id = "YOUR_FILE_ID"
    url = f"https://drive.google.com/uc?id={file_id}&export=download"

    print(f"Downloading model to {model_path}...")
    response = requests.get(url, stream=True)

    model_path.parent.mkdir(parents=True, exist_ok=True)

    with open(model_path, 'wb') as f:
        for chunk in response.iter_content(chunk_size=8192):
            f.write(chunk)

    print("Model downloaded successfully!")

if __name__ == "__main__":
    download_model()
```

#### C. `app.py`에서 호출

```python
# app.py 상단에 추가
from download_model import download_model

# 서버 시작 시 모델 다운로드
download_model()
```

## 트러블슈팅

### 1. Vercel 빌드 실패

**문제**: `Module not found: Can't resolve '@/...'`

**해결**:
```bash
# vite.config.ts의 alias 설정 확인
resolve: {
  alias: {
    '@': '/src',
  },
}
```

### 2. Render 빌드 실패

**문제**: `numpy` 설치 에러

**해결**:
```bash
# Build Command를 다음과 같이 수정:
pip install --upgrade pip && pip install "numpy>=1.21.0,<1.27.0" && pip install -r requirements.txt
```

### 3. CORS 에러

**문제**: `Access to fetch at ... has been blocked by CORS policy`

**해결**:
```python
# backend/app.py에 CORS 설정 확인:
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 프로덕션에서는 실제 도메인만 허용
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 4. 모델 파일 없음

**문제**: `Model file not found`

**해결**:
- 외부 스토리지에서 다운로드 스크립트 실행 확인
- 또는 Git LFS로 모델 파일 추가

### 5. 무료 플랜 제한

**Render 무료 플랜**:
- 비활동 시 자동 sleep (요청 시 재시작, 첫 요청 느림)
- 한 달 750시간 제한

**해결**:
- 항상 깨어있게 하려면: 유료 플랜 ($7/월)
- 또는 매 14분마다 health check 요청 (cron job)
