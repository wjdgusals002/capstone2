## 1. 개요

### 목적
드론 부품 세그멘테이션 결과를 사용자에게 직관적으로 제공하는 **웹 기반 대시보드**

### 주요 기능
- ✅ 드론 이미지 업로드 및 실시간 분석
- ✅ 세그멘테이션 결과 시각화 (컬러 마스크, 오버레이)
- ✅ 부품별 검출 정보 및 신뢰도 표시
- ✅ 이상 탐지 결과 리포트
- ✅ 모델 성능 평가 대시보드
- ✅ 학습 곡선 및 메트릭 시각화
- ✅ PDF 보고서 다운로드 (인쇄 기능)

### 사용자 경험
```
사용자 → 이미지 업로드 → 자동 분석 → 결과 확인 → 보고서 다운로드
```

### 4.1 드론 분석 페이지 (`/`)

#### 경로
- **URL**: `/` (기본 페이지)
- **컴포넌트**: `<DroneAnalysis />`

#### 주요 기능
1. **이미지 업로드**

   - 지원 형식: JPG, PNG
   - 실시간 미리보기

2. **자동 분석**
   - 이미지 선택 시 자동으로 백엔드에 전송
   - 프로그레스 바로 진행 상태 표시
   - 단계: 업로드 → 예측 → 완료

3. **결과 표시**
   - 분석 완료 후 `<DroneResults />` 컴포넌트로 전환
   - Executive Summary, 부품별 검출 정보, 이상 탐지 결과

### 4.2 모델 평가 페이지 (`/evaluation`)

#### 경로
- **URL**: `/evaluation` (Navbar에서 전환)
- **컴포넌트**: `<ModelEvaluation />`

#### 주요 기능
1. **모델 성능 요약**
   - 6개 메트릭 카드 (1×6 레이아웃)
   - 최고 정확도, mIoU, mDice, Best Loss, 학습 에포크, 데이터셋 크기

2. **학습 곡선**
   - Accuracy 학습 곡선 (Train / Validation)
   - Loss 학습 곡선 (Train / Validation)
   - Recharts LineChart 사용

3. **부품별 성능**
   - 바 차트로 클래스별 IoU 표시
   - 드론 부품 5개 (배경 제외)

4. **종합 성능 레이더 차트**
   - 5개 메트릭: 정확도, 정밀도, 재현율, F1 Score, mIoU
   - 육각형 레이더 차트 (Recharts RadarChart)

5. **혼동 행렬 (Confusion Matrix)**
   - 6×6 테이블 (배경 + 드론 부품 5개)
   - 색상 코딩: 대각선(초록) vs 오분류(빨강)
   - 호버 시 확대 효과

#### 데이터 소스
- API: `/model/info` → 모델 정보 및 성능 지표
- API: `/model/history` → 학습 히스토리 (epoch별 데이터)

const handleImageUpload = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) {
    setSelectedFile(file);
    const reader = new FileReader();
    reader.onloadend = () => {
      setSelectedImage(reader.result as string);
      startAnalysis(file);  // 자동 분석 시작

    reader.readAsDataURL(file);

const startAnalysis = async (file: File) => {
  setProcessingState({ stage: 'uploading', progress: 30 });
  setProcessingState({ stage: 'predicting', progress: 50 });

  setPredictionResult(result);
  setProcessingState({ stage: 'complete', progress: 100 });
  setShowResults(true);
};

## 6. API 통신

### 파일: `services/api.ts`

#### API 클라이언트 클래스
```typescript
class ApiService {
  private baseUrl: string;

  constructor(baseUrl: string = API_BASE_URL) {
    this.baseUrl = baseUrl;
  }

  // 예측 요청
  async predict(imageFile: File, gtMask?: File): Promise<PredictionResult> {
    const formData = new FormData();
    formData.append('file', imageFile);
    if (gtMask) formData.append('gt_mask', gtMask);

    const response = await fetch(`${this.baseUrl}/predict`, {
      method: 'POST',
      body: formData,
    });

    if (!response.ok) {
      throw new Error(`Prediction failed: ${response.statusText}`);
    }

    return response.json();
  }

  // 모델 정보 조회
  async getModelInfo(): Promise<ModelInfo> {
    const response = await fetch(`${this.baseUrl}/model/info`);
    if (!response.ok) {
      throw new Error(`Failed to fetch model info: ${response.statusText}`);
    }
    return response.json();
  }

  // 학습 히스토리 조회
  async getTrainingHistory(): Promise<TrainingHistory> {
    const response = await fetch(`${this.baseUrl}/model/history`);
    if (!response.ok) {
      throw new Error(`Failed to fetch training history: ${response.statusText}`);
    }
    return response.json();
  }

  // 헬스체크
  async healthCheck(): Promise<{ status: string; service: string }> {
    const response = await fetch(`${this.baseUrl}/health`);
    if (!response.ok) {
      throw new Error(`Health check failed: ${response.statusText}`);
    }
    return response.json();
  }
}

export const apiService = new ApiService();
```
